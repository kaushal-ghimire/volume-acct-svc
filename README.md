Installation <br>
1. Clone the Repository: <br>
&nbsp;&nbsp;&nbsp;git clone https://github.com/your-username/volume-acct-svc.git <br>
&nbsp;&nbsp;&nbsp;cd volume-acct-svc <br><br>

2. Install Dependencies <br>
&nbsp;&nbsp;&nbsp;npm install <br>
&nbsp;&nbsp;&nbsp;(Installs dependencies including Express, Sequelize, PostgreSQL, OracleDB, Winston, etc.) <br><br>

3. Environment Setup <br>
&nbsp;&nbsp;&nbsp;-> Create a .env file in the root directory and configure database connections <br><br>

4. Running the Project - Development Mode (with hot reload) <br>
&nbsp;&nbsp;&nbsp;npm run dev <br>
