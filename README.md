Installation
1. Clone the Repository
    git clone https://github.com/your-username/volume-acct-svc.git
    cd volume-acct-svc
   
2. Install Dependencies
     npm install
        (Installs dependencies including Express, Sequelize, PostgreSQL, OracleDB, Winston, etc.)

3. Environment Setup
      -> Create a .env file in the root directory and configure database connections
   
4. Running the Project-Development Mode (with hot reload)
     npm run dev
